# Tabla de caracteres para una fuente personalizada
#
# Formato: original=reemplazo   (una pareja por línea)
# Al reconstruir el HCB, cada carácter "original" se escribe como "reemplazo",
# que la fuente personalizada del juego dibuja como el carácter original.
# El reemplazo debe existir en Shift-JIS. Los katakana de ancho simple
# (ｱ, ｲ, ｳ...) ocupan 1 byte; los de ancho completo (ア, イ, ウ...) ocupan 2.
#
# EJEMPLO: sustituye los reemplazos por los katakana que usa TU fuente.
#
# á=ｱ
# é=ｲ
# í=ｳ
# ó=ｴ
# ú=ｵ
# ñ=ｶ
# ü=ｷ
# ¿=ｸ
# ¡=ｹ
# Á=ｺ
# É=ｻ
# Í=ｼ
# Ó=ｽ
# Ú=ｾ
# Ñ=ｿ
